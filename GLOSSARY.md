# Vira Voto

O hub reúne ferramentas de mobilização e conteúdos para compartilhar, com publicação após curadoria.

## Linguagem

**Ferramenta**:
Um recurso interativo que uma pessoa usa para realizar uma tarefa, como consultar um mapa ou gerar um QR code.
_Evitar_: Conteúdo, material compartilhável

**Conteúdo**:
Um material que uma pessoa pode consumir ou compartilhar, como uma imagem ou um vídeo.
_Evitar_: Ferramenta

**Curadoria**:
A avaliação de um envio para decidir sua publicação no hub e, no caso de uma ferramenta, se ela pode ser usada dentro do hub.
_Evitar_: Publicação automática
