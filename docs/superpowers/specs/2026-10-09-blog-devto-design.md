## Data and trust boundaries
GET fixed https://dev.to/api/organizations/techcontrabolsonaro/articles?page=N&per_page=6 (six shown; bounded next-page probe when current page is full). No tag parameter or category filter. Each row must identify organization.username=techcontrabolsonaro and published_at. GET fixed https://dev.to/api/articles/{numeric id} for detail; independently verify organization, published date and id. Reject missing/foreign/unpublished detail as not found; wrong slug redirects to /blog/{id}/{encoded upstream slug}. Validate numeric identifiers before network calls; no arbitrary API URL input; redirect:error; request deadline 8s. Accept application/vnd.forem.api-v1+json and identifying User-Agent. Next fetch next.revalidate=300, React cache deduplicates render calls. Errors and 429 remain explicit unavailable states with retry, never false 404. Empty feed is explicit; successful cached data may remain stale while Next revalidates. No fake articles/covers when upstream is empty or cover null.

Local permalink is the share URL and og:url. SEO alternates.canonical uses validated HTTPS DEV.to original URL (host exactly dev.to, no credentials, matching organization/slug), falling back to constructed DEV.to source. Never trust external canonical_url blindly; external/nonmatching canonical is ignored under this DEV.to-origin contract. Explicit author name, username/profile, organization, date, reading time, actual tags and original article link.

## Sanitizer
sanitize-html, maintained in apostrophecms/apostrophe/packages/sanitize-html (old standalone repo moved in 2026). Server-only dependency. Explicit allowed prose/headings/lists/blockquote/pre/code/spans/tables/figures/images/details. Preserve UTF-8, text order, escaped code and line breaks. No script/style/svg/math/iframe/object/embed/form/input/media/event handlers/style/id/name/srcset or arbitrary classes. Only HTTPS links without credentials (relative links resolved against dev.to; local heading fragments retained with prefixed IDs). Images only media.dev.to, media2.dev.to, dev-to-uploads.s3.amazonaws.com, dev-to-uploads.s3.us-east-2.amazonaws.com; strip mixed HTTP/data/blob/private-host images. Add lazy loading, no-referrer, safe link rel. No automatic embeds; accessible source link remains available. Parser library, never regex HTML sanitizing.
